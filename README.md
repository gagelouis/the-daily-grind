# The Daily Grind

A responsive website for a fictional neighborhood coffee shop based in Seattle, Washington.

## Project Overview

The Daily Grind is a self-initiated design and development project exploring the relationship between brand identity, user interface design, and front-end development.

The goal was to create a warm, approachable digital experience that reflects the personality of a local coffee shop through typography, photography, color, and thoughtful layouts.

## Tools & Technologies

- Figma
- Adobe Illustrator
- Adobe Photoshop
- Visual Studio Code
- HTML5
- CSS3
- JavaScript
- Google Lighthouse

## Features

- Responsive desktop, tablet, and mobile layouts
- Interactive mobile navigation
- Semantic HTML structure
- Keyboard-accessible navigation
- Optimized WebP photography
- Lazy loading and image prioritization
- Custom typography and color system
- Custom SVG favicon

## Design Process

1. Establish the visual direction and brand identity.
2. Design desktop and mobile interfaces in Figma.
3. Translate the designs into HTML and CSS.
4. Develop interactive navigation using JavaScript.
5. Test responsive layouts and accessibility.
6. Optimize images and website performance.

## Performance

Following image and font optimization, the website achieved the following scores in a local Google Lighthouse audit:

- Performance: 99/100
- Accessibility: 100/100
- Best Practices: 100/100
- SEO: 100/100

The recorded performance score improved from 79 to 99.
